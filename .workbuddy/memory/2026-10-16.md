## 云顶浮岛：鱼重做 + 鸟居小岛右移

### 鱼（`src/three/surrounds/islandSurround.ts`）
- **数量 7 → 3**（用户要求"减少到 2、3 条"）。
- **体型**：原来身子就是"一个球压扁"（`SphereGeometry(0.5)` scale `[1.05,0.6,1.6]`，宽长比 0.66），
  球两头都圆，怎么调都显胖 —— 用户原话"怎么都那么肥"。
  现在拆成 **前段椭球（头）+ 后段圆锥（收尖的尾柄）+ 后掠三角尾鳍 + 背鳍 + 一对胸鳍**，
  长宽比约 4:1，尾端收尖，1 个 InstancedMesh（6 个图元合批）。
- **"在水里"**：俯视时鱼沉下去的那半被不透明海面切掉，从上看不出任何区别 ——
  所以光靠"沉下去"没用。改成两个线索：
  1. 只露背脊：中心压到 `0.01 − 0.062×size`，约六成身子在水面下；
  2. **水纹环**：`RingGeometry` 压扁成椭圆（横向 ×1.4、纵向 ×0.85），
     加色混合，**靠 `instanceColor` 写黑来做淡入淡出**（加色下黑色=不画，
     不用逐实例透明）。两圈沿航向**前后错开**拖在鱼身后 ——
     同心圆会读成一个靶子，前后错开才像尾迹。
- **水纹要浅**（用户第二次反馈）：峰值 alpha `0.2 → 0.11`，环更细（0.82~0.87），
  颜色 `(0.88, 0.98, 1.0)×a` 的极浅青白。
- 鱼身配色往水色 `#7fd8dc` 里 `lerp 0.22`，隔着水看饱和度会掉，
  纯色贴在水面上像贴纸。

### 鸟居小岛与木桥右移
- 位置提到**模块级常量** `ISLET_A = −33° / ISLET_L = 30`
  （原来是散在四处的硬编码 `(24.8, −9.7)`：小岛本体、远处小岛避让、睡莲避让、水草避让 ——
  改位置要改四个地方，漏一个就穿模）。
- 轴测里 +x 朝右下、+z 朝左下，**"屏幕往右" = x 变大、z 变小**，
  所以 −21.4° → −33° 就是右移；屏幕上约右移 7 个单位。
- 木桥从 4.7 拉长到 8.1（`from 18.6` 不动，`to = ISLET_L − R×1.05`），
  桥墩从"两头各一根"补成"两头 + 中间"一根（7.7 米净跨只靠两头会像悬空木条）。
- **鸟居横梁朝向改成常数 `TORII_YAW`（≈136.4°）**：横梁在屏幕上是否水平只取决于相机方位，
  与鸟居站在哪儿无关；原来的 `π/2 − atan2(cz,cx) + 25°` 会跟着位置转，
  小岛一挪门梁就歪 11.6°。
