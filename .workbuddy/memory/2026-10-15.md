# 2026-10-15 · 3D 飞行棋 视觉迭代

## 棋子重做（经典小人造型）
`pawnProfile()`（board3d.ts）整个重写：旧版是从底到顶一路收尖的水滴/陀螺形，
没有独立的头，远看像根钉子。新版按「球头 → 细颈 → 钟形身躯 → 倒角底座」四段设计，
轮廓高 1.0 / 底半径 0.32（宽高比 0.64），并配套把 pieces.ts 里的
影子 1.9→1.24、地环 0.72-0.98→0.44-0.60、护盾泡 0.86→0.60、冻结晶 0.78→0.56、
默认 height 1.18→1.35 一起改 —— **轮廓一瘦，所有贴地元素都得跟着缩，否则"影比人大"**。
半程纪念碑的巨型棋子同轮廓，缩放 2.05→2.6 补体量。
材料顺手提亮：roughness .22→.18、envMapIntensity 1.15→1.25。

## 城市（city.ts）改动
- **房子**：6 栋 → 3 栋 + 1 座塔。`Rect` 新增 `wide`（宽板楼），地标 6/7 层压到 4/5 层，
  体型系数 0.84→0.7、0.58-0.74→0.5-0.64。宽板楼最初 14×6.2，后按需求旋转 90°
  （长宽对调成 6.2×14，长边沿 Z）。
- **房子不再压草地**：build/tower/parking 地块的底色从绿改成浅灰铺装 #e2e7ea；
  且无裙房的楼原本悬空 0.2（楼板底 0.52 vs 地面 0.31），补了 0.34 高的落地基座。
- **删放射大道**：4 条从环城路铺到外圈的大道 + 它们的中心虚线 + 路侧路灯全删，
  环城路成为闭合环路。（`CITY.ave/bandB` 仍被 buildCars 的 fixed 分支引用，保留常量。）
- **路灯**：原来放在 `makeRing(25)` 的中心线上 = 车道正中。改到外侧人行道 28.4，
  旋转从 `atan2(tx,tz)`（切向）改成 `atan2(nx,nz)`（法向），灯臂才垂直路沿探到路面上方。
  外侧行道树 4.2→4.8 让位。
- **小蛮腰**：`cantonTower()` 用「双族直杆」造直纹双曲面 —— 底圆连顶圆错开扭角，
  直杆中段自然收腰。r0=5.0/r1=4.2/twist=1.9rad → 腰径 2.68、位于 56% 高（比例 0.54）。
  60 根斜柱 + 8 道环梁 + 玻璃内芯(lathe) + 观景层 + 天线 + 红色障碍灯，
  全部进 metal/glass/accent 三个既有合批，零新增 draw call。
  **收腰深浅只由扭角决定：r0=r1 时腰必在半高**，这是调型的关键公式。
  塔位：先放 slot6，后按用户要求与 slot5（地标 B）对调 —— 地标 B 退成绿地。
- **球场树**：court 分支的 `scatterTrees` 会把树种在草皮上（水面同理，一并删了）。
  新增 `scatterAround(r, n, keepOut)`：拒绝采样，keepOut 可为矩形半宽
  `{kx,kz,circle?}`（塔座用圆形禁区 7.8）。球场边 9 棵、塔脚 6 棵、楼边 3 棵
  （keepOut 用实际楼投影 maxBw/maxBd）。

## 验证技巧（本项目）
- 相机是**正交**且取景按棋盘定：`frustum = max(minFrustum, baseFrustum/aspect) / zoom`。
  外围街区（半径 39 的街区环）平时在画面外。两个办法：
  ① 极宽视口（3600×760）横向撑大；② **滚轮缩小** —— 注意这个项目里
  `k = exp(-deltaY*0.0012)`，**向下滚（deltaY>0）才是缩小**，向上滚是放大。
  Playwright: `page.mouse.wheel(0, 3000)` × 26 次即可看全城。
- 截图脚本：/tmp/pwtool/cityview.cjs（进局+缩小+可 CLIPS 裁剪）、zoom2.cjs（指定视口/裁剪）。
- dev server 用 `npx vite --host 0.0.0.0 --port 5288` 起在 5288，冷启动要 ~20-35s，
  刚起就 fetch 会 ERR_CONNECTION_REFUSED，要轮询等。
